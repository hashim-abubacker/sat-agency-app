# Project Guidance for AI Agents

See root [AGENTS.md](file:///AGENTS.md) and [README.md](file:///README.md) for full context on Simple Agency Tool (SAT).

## Quick Checklist for New AI Sessions:
1. Verify `.env` is populated with `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
2. Run `npm install` if `node_modules` is missing.
3. Reference `05_Database_Schema.md` and `Simple_Agency_Tool_PRD_v1.1.md` before making database or architectural changes.
